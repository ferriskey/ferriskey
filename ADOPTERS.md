# Adopters of FerrisKey

This file lists organizations that use FerrisKey in some capacity. It gives the community, prospective adopters and the CNCF a view of the project's adoption.

For the full definition of an adopter, see the [CNCF TOC FAQ](https://github.com/cncf/toc/blob/main/FAQ.md#what-is-the-definition-of-an-adopter). Sponsors who fund the project are listed separately in the [README](./README.md#sponsors) and on [ferriskey.rs](https://ferriskey.rs).

## Adopter types

| Type | Description |
| ---- | ----------- |
| End-User Organization | Uses FerrisKey internally or builds on it, without selling it as a service |
| Service Provider | Offers FerrisKey as a core component of a service (cloud provider, SaaS, managed service) |
| Project | Open source project that integrates with or depends on FerrisKey |
| Consultancy | Helps others build solutions with FerrisKey |

Customers of a service provider are transitive adopters and are not listed individually.

## Adding your organization

Open a pull request that adds a row to the table above, with a link to your organization and one sentence on how you use FerrisKey. If your organization needs to stay anonymous, list the industry instead of the name (for example "European healthcare provider").
