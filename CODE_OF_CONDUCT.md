# Code of Conduct

FerrisKey follows the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).

It applies to every space the project runs: this repository and the other repositories of the [ferriskey](https://github.com/ferriskey) organization, the [Discord server](https://discord.gg/WVV5rq8ANb), and any event where someone represents the project.

## Reporting

If you witness or are subject to behavior that violates the Code of Conduct, report it to the maintainers at <conduct@ferriskey.rs>. You can also contact any maintainer listed in [MAINTAINERS.md](./MAINTAINERS.md) directly.

Reports are handled confidentially. You can expect a first response within three business days.

Once FerrisKey is a CNCF project, incidents can also be reported to the [CNCF Code of Conduct Committee](https://www.cncf.io/conduct/committee/) at <conduct@cncf.io>, following the CNCF [Incident Resolution Procedures](https://github.com/cncf/foundation/blob/main/code-of-conduct/coc-incident-resolution-procedures.md).

## Enforcement

The maintainers review every report, decide on the action the Code of Conduct calls for, and apply it. Maintainers who do not follow or enforce the Code of Conduct may be removed from the project team.
