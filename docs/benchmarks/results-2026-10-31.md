# Benchmark results — 2026-10-31

Wall-clock results of the Criterion suites in the repository, run on
`main` at commit `3a10fbd` (v0.10.0).

CodSpeed tracks regressions on every pull request in simulation mode, which
counts instructions rather than time. The figures below are the wall-clock
counterpart: what one operation actually costs on a modest machine.

## Environment

| | |
|---|---|
| CPU | Intel Xeon @ 2.10 GHz, 2 vCPU (shared cloud VM) |
| Memory | 7 GiB |
| Kernel | Linux 6.18 |
| Toolchain | rustc 1.97.0, `bench` profile |
| Harness | Criterion, 100 samples per benchmark |

A shared 2 vCPU VM is noisy: read these as orders of magnitude, not as
precise values, and compare runs only on the same machine.

## `ferriskey-authz-cedar`

The `decide` bench evaluates a realm with 1000 policies (900 RBAC, 90 ABAC,
10 forbid) against a principal slice of about 1000 entities (500 held roles,
400 groups across 40 organizations of depth 10, 99 organizations).

| Benchmark | Median | Interval |
|---|---:|---|
| decide 1000 policies x 1000 entities | 12.11 ms | 11.92 – 12.30 ms |
| compile 1000 policies | 48.41 ms | 47.44 – 49.41 ms |

## Reading the numbers

- Password hashing dominates the password grant: about 16 ms per argon2
  operation, by design. Client secret checks stay under 200 ns, and a wrong
  secret costs about the same as a right one.
- Keeping the parsed RSA key saves about 550 µs per signature (897 µs →
  348 µs). Signing remains the most expensive step of token issuance after
  argon2; verification is about 14 times cheaper than signing with a kept
  key.
- Claims assembly and scope resolution are in the low microseconds and do not
  weigh on the token endpoint.
- Verifying 1000 chained audit events costs under 1 ms, i.e. under 1 µs per
  event, in line with hashing one event.
- A Cedar decision against this worst-case realm costs about 12 ms, the same
  order as an argon2 verification. Compilation (48 ms) happens once per rule
  set change, not per request. Realms of this size are the case to watch on
  the AuthZEN endpoint.

## Reproduce

```bash
cargo bench -p ferriskey-benchmarks
cargo bench -p ferriskey-authz-cedar --bench decide
```
